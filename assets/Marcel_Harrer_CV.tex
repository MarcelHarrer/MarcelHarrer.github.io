\section{Experience}
\role{Senior AI Engineer}{Fivesquare}{Remote $\cdot$ Mar 2026 -- Present}\begin{itemize}
\item Architected and own end to end a production multi-agent system that routes incoming email and scanned mail for 50 government departments to the right case file: around 10 million emails a year, 90\% accuracy against how staff filed the same emails, about 20\% fully auto-assigned, and around 3,000 staff hours saved so far.
\item Self-improving by design: a nightly learner turns staff corrections into skills in a git-backed memory repository, a challenger agent runs beside the live one so changes prove themselves first, and every decision is traced in Langfuse. Uncertain cases go to a person.
\item Built the retrieval layer (Qdrant with BGE-M3 dense + sparse vectors) and the benchmark that measures it, with leak-free train/validation/test splits.
\item Built the confidence score that decides which emails are auto-assigned (decision-gate model, token log-probs, self-confidence), automatic subject area, case title and keywords, and vision OCR for scanned letters.
\end{itemize}
\role{AI Engineer (Freelance)}{Property management client}{Remote $\cdot$ Mar 2025 -- Dec 2025}\begin{itemize}
\item Built a Text-to-SQL agent (LangGraph) that lets the client's non-technical staff pull data from PostgreSQL in plain English, removing their dependence on engineers for routine reports.
\item Designed the modular tool interfaces the agent uses to query databases, reason over structured data, and trigger email workflows, so it handles multi-step requests end to end instead of one-off queries.
\end{itemize}
\role{AI Research Engineer}{ImageTwin}{Jan 2024 -- Dec 2025}{\small\textit{Part-time in 2025, concurrent with the freelance role above.}}\par\vspace{-1pt}\begin{itemize}

\item Co-built an end-to-end pipeline to detect AI-generated images, from labeling training data through automated evaluation.
\end{itemize}
\role{AI Engineer}{Financial Market Authority (FMA)}{Vienna, Austria $\cdot$ Dec 2022 -- Dec 2023}\begin{itemize}
\item Built an AI search assistant (RAG with FAISS and transformer embeddings) that gave regulators instant, source-backed answers from thousands of German-language regulatory documents.
\item Made large regulatory archives searchable by meaning rather than exact wording (SBERT similarity), so staff could surface relevant rules they would otherwise miss.
\end{itemize}
